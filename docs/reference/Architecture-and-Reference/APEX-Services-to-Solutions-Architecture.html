Reading the Stack

Top-down: Outcomes are what the client experiences. Solutions are how Deloitte delivers them. Services are the building blocks. Foundation is the shared substrate.

Bottom-up: A new client starts at Foundation (no client opts out), subscribes to 2–3 Services, which compose into a named Solution, which delivers a measured Outcome.

Solution Composition Pattern

A Solution typically draws from 3–7 services across 1–3 Practices. Cross-practice solutions (like Autonomous GSE) prove the value of APEX's shared grammar — schemas, gates, tooling, and observability are interoperable by construction.
