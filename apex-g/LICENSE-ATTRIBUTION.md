# LICENSE-ATTRIBUTION — APEX-G (stub)

APEX-G is a stub package today; this attribution document is in place
**from the start** to reflect that APEX-G is a real, audit-defensible
sibling product to APEX-M and APEX-A.

## Google Cloud products planned for integration

When APEX-G is commissioned and built, it will integrate with the
client's existing Google Cloud investment using:

- **Google Cloud Platform** — Compute Engine, Cloud Run, Cloud Storage,
  BigQuery, Pub/Sub, Eventarc, Cloud KMS, Secret Manager, Cloud IAM,
  Workload Identity Federation
- **Vertex AI** — Agent Builder, Agent Engine, text-embedding-005,
  Vector Search, Model Garden, safety filters
- **Google Workspace** — Drive, Gmail, Chat, Docs (for productivity
  surfacing equivalent to M365 in APEX-M)
- **Looker / Looker Studio** — BI surface (Power BI equivalent)
- **Chronicle SecOps** — SIEM (Microsoft Sentinel equivalent)
- **Sensitive Data Protection (Cloud DLP)** — classification
  (Microsoft Purview Information Protection equivalent)

## Independence posture

Per Deloitte's Microsoft Technology & Services Practice, this
attribution records that APEX-G:

- **Will not** be a redistribution of any Google Cloud product
- **Will not** be positioned as preferred over APEX-M or APEX-A
- **Does not** have an alliance posture with Google Cloud — APEX-G
  exists to honor a client's existing Google Cloud investment when
  their cloud architecture board has approved that as their primary
  substrate
