## 2. Telco-level

20M home-internet HH × 30–45% attach × $190–335 = **$1.1–3.0B / yr in Walmart Channel GP**.

## 3. Cost stack

| Cost | Per HH / mo |
|---|---|
| Inference + integration | $0.20–0.50 |
| Walmart-MCP partner-quota fees | $0.10–0.30 |
| Customer-care load | $0.30–1.00 |

Gross margin envelope: 78–90%.

## 4. Risks

- **Walmart-direct app dominance** — customer keeps using Walmart's app instead of the orchestrator. Mitigated by errand-chain wedge.
- **Multi-retailer pricing transparency** — customer sees lower Target price; trust drops if orchestrator hides it. Mitigated by transparent surfacing.
- **Pharmacy PHI compliance** — non-trivial regulatory footprint. Mitigated by RTL-02 being independently subscribable.
