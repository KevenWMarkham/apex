# Home OTA & itinerary builder

**Practice:** TMT — Technology, Media, Telecom
**Catalog index:** 33
**Service code:** `TMT-TEL-HOM-13`
**Headline KPI:** ↑ trip-build time saved; ↑ booking accuracy

## Description

Multi-segment trip planning via Expedia, Booking.com, Kayak, Google Travel. Acts as fallback to direct-partner sub-agents when (a) direct inventory doesn't cover the destination, (b) the customer wants a bundled flight+hotel+car package, or (c) the long-tail booking requires meta-search.

**Anchor partner:** Expedia.

## Status

Featured scenario for the Travel & Hospitality agentic pack.
