Reading the Diagram

  • Top-down: human-facing decision surfaces (L7) sit at the top; airside source systems (L1) at the bottom.
  • Each layer is a discipline boundary — APEX Core defines the contract between layers, the edition (ICE / TH) populates it.
  • Amber tag on a component highlights the autonomous-GSE-specific responsibility within that generic Microsoft service.
  • Cross-cutting band on the right applies to every layer simultaneously — identity, governance, observability, and security are not optional.
  • Service bindings (lower right) name the catalogued APEX SKUs that this architecture instantiates for an autonomous-GSE engagement.

Microsoft Stack Coverage

  • 22 distinct Microsoft services, all native to Azure / Fabric / Power Platform / D365.
  • Zero third-party runtime dependency in the data and intelligence planes.
  • Independence-compliant: client-tenant data plane; no Deloitte-side telemetry retention.
