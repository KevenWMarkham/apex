# Home vehicle readiness

**Practice:** TMT — Technology, Media, Telecom
**Catalog index:** 27
**Service code:** `TMT-TEL-HOM-07`
**Headline KPI:** ↑ avoided unplanned vehicle downtime; ↓ EV-charge cost

## Description

EV-charge scheduling and maintenance triage across the household's connected vehicles. Reads TPMS, fuel/charge, odometer, and maintenance-due signals from GM OnStar / Ford SYNC / Stellantis Uconnect / Tesla / Toyota Connected. Coordinates with ChargePoint / EVgo / Electrify America for cost-optimized charging windows, and with service networks (Jiffy Lube, Firestone, dealer networks) for scheduled-maintenance booking. UBI insurance partners share telematics-driven premium discounts.

Featured scenario for the Telco Home Agentic pack.
