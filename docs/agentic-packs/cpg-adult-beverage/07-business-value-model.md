# 07 — Business Value Model (Beverage Channel)

> _Draft — lower attach rate, higher per-engaged-subscriber ARPU, materially higher gross margin than retail._

## Per-household envelope (engaged subscriber)

| Source | Annual |
|---|---|
| Subscription ($4.99 × 12) | $60 |
| BEV-01 replenishment (4–8 orders × $80 × 7%) | $25–50 |
| BEV-02 allocation alerts (conversions) | $15–40 |
| BEV-03 cocktail concierge (mostly drives BEV-01 + Retail) | $5–15 indirect |
| BEV-04 tasting events (booking commission) | $30–80 |
| **Blended GP / engaged HH / yr** | **$135–245** |

## Collector segment (~3% of subscribers, ~30% of revenue)

| Source | Annual |
|---|---|
| Subscription | $60 |
| BEV-02 successful allocation conversions (10–25 / yr × $250 × 5%) | $125–315 |
| BEV-01 standard-release orders | $80–150 |
| BEV-04 tour-package bookings | $150–500 |
| **Blended GP / collector HH / yr** | **$415–1,025** |

## Telco-level

20M HH × 8–18% attach × $135–245 (blended) = **~$220M–880M / yr in Beverage Channel GP**.

Lower than Home / Travel / Retail / Mobility, but the gross-margin profile is the best in the marketplace (less customer-care load, less infrastructure, more brand-funded marketing).

## Cost stack

| Cost line | Per HH / mo |
|---|---|
| Inference + integration | $0.10–0.30 |
| Brand-owner API fees | $0.05–0.20 |
| Age-verification (per order) | $0.20–0.50 |
| State-rules-engine fees | $0.10–0.30 |
| Customer-care load (low) | $0.20–0.60 |

Gross margin envelope: **85–92%** — the best in the marketplace.

## Risks

- **State compliance moves.** Single state changing rules can pause Channel operations in that state.
- **Allocation-scalper litigation.** If secondary-market players claim the Telco's reserve-hold mechanism is anticompetitive, regulatory exposure increases.
- **Brand-owner direct.** Sazerac could build their own direct app — though without the Telco's compliance + Channel-bundle scale, it would be smaller.
- **Generational shift.** Younger cohorts drink less spirits; bourbon-allocation demand could soften over 10-year horizon.
