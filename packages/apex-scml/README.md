# apex-scml

APEX **SCML** (Supply Chain Markup Language) canonical entities for the RC Practice.

Standards incorporated (`Industry-Standards-Incorporation-Plan.md` §6.1):

- **GS1** — GTIN (SKU), SSCC (Shipment), GLN (Location) — Pattern A
- **EPCIS** — Supply-chain event messages — Pattern D (`translators/`)
- **Schema.org** — Product / Offer interop — Pattern D (`translators/gs1_to_schema_org.py`)

Entities: SKU · Location · Lot · Shipment · Supplier · Item.
