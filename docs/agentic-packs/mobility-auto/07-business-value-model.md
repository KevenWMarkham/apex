# 07 — Business Value Model (Mobility Channel)

## Per-household

| Source | Annual / Mobility-Channel HH |
|---|---|
| Subscription ($9.99 × 12) | $120 |
| MOB-01 connected-services attribution | $20–40 |
| MOB-02 dealer service action commerce | $30–60 |
| MOB-03 next-vehicle (amortized) | $80–150 |
| MOB-04 TFS refi + TIMS UBI share | $40–100 |
| **Blended GP / HH / yr** | **$290–470** |

## Telco-level

20M HH × 20–35% attach × $290–470 = **$1.2–3.3B / yr GP**.

## Margin profile

| Cost line | Per HH / mo |
|---|---|
| Inference + integration | $0.30–0.70 |
| OEM partner-API fees | $0.20–0.50 |
| Customer care (high — auto-service heavy) | $1–3 |

Gross margin envelope: 75–88%.

## Risks

- **OEM-direct app lock-in** (Toyota app users may resist) — mitigated by multi-vehicle wedge
- **Dealer-network capacity constraints** — services rejected during high-demand periods
- **Insurance-state regulatory complexity** — MOB-04 must clear all 50 states
- **Lease-end / refi cycle is 36–60 months** — long attribution window for MOB-03

## Upside scenarios

- Tesla opens its Supercharger to other OEMs at scale → MOB-01 wins on EV-fleet coverage
- Captive auto-insurance regulation eases telematics-data sharing → UBI rev-share doubles
